# Decisões Arquiteturais

## ADR-001 - Escolha do Next.js

### Data

2026-07-21

### Contexto

Era necessário escolher um framework React para o portfólio.

### Decisão

Foi escolhido Next.js 16.

### Motivos

- App Router
- SEO
- React Server Components
- Excelente integração com TypeScript

### Alternativas consideradas

- Vite
- Astro
- Remix

### Consequências

- Deploy simplificado.
- Melhor indexação.
- Estrutura baseada em rotas.
