# Internacionalização

## Biblioteca escolhida

next-intl

## Motivos

- Integração nativa com o App Router do Next.js.
- Boa experiência com Server Components.
- Excelente documentação.
- Estrutura simples para manutenção.
- Escalável para novos idiomas.

## Estrutura adotada

- `src/i18n`: configuração da biblioteca.
- `src/messages`: arquivos de tradução.

## Convenções

- Idiomas internos: `pt` e `en`.
- Português como idioma padrão.
- Inglês acessível pelo prefixo `/en`.
