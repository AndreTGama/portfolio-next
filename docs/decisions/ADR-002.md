# ADR-002 - Idioma padrão

## Contexto

O portfólio tem como objetivo atingir recrutadores brasileiros e internacionais.

## Decisão

O idioma padrão será inglês.

O português ficará disponível em `/pt`.

## Motivos

- Público internacional.
- Melhor experiência para recrutadores estrangeiros.
- Consistência com README, commits e documentação em inglês.
- SEO voltado para inglês na URL principal.

## Consequências

Usuários brasileiros precisarão trocar o idioma na primeira visita.
