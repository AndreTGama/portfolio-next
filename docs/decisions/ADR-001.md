# ADR-001 - Escolha do Framework

## Status

Accepted

## Data

2026-07-21

## Contexto

Era necessário escolher a tecnologia base para o desenvolvimento do portfólio.

O projeto deveria atender aos seguintes requisitos:

- Excelente SEO.
- Alto desempenho.
- Facilidade de deploy.
- Boa experiência para recrutadores.
- Ecossistema moderno.
- Forte demanda no mercado de trabalho.
- Suporte à internacionalização.
- Integração com TypeScript.

## Decisão

Foi escolhido o **Next.js 16**, utilizando:

- App Router
- React 19
- TypeScript
- Tailwind CSS

## Motivos

- Framework amplamente utilizado no mercado.
- Excelente SEO utilizando Server Components.
- Ótima integração com TypeScript.
- Estrutura escalável.
- Excelente experiência para deploy (Docker, AWS, Coolify, Vercel).
- Grande comunidade e documentação.
- Compatível com `next-intl`.
- Boa experiência para construção de blogs e portfólios.

## Alternativas consideradas

### Vite

Muito rápido para desenvolvimento, porém exigiria mais configuração para SEO e renderização.

### Astro

Excelente para conteúdo estático, porém menor demanda no mercado e menor flexibilidade caso o projeto cresça.

### Remix

Ótima arquitetura, porém menor adoção no mercado quando comparado ao Next.js.

## Consequências

### Positivas

- Excelente SEO.
- Projeto preparado para crescimento.
- Boa aceitação no mercado.
- Facilidade para adicionar novas funcionalidades.
- Integração simples com Docker.

### Negativas

- Curva de aprendizado maior devido ao App Router.
- Estrutura mais complexa do que frameworks SPA tradicionais.
